PICAFSO: Particle Identification, Counting, and Analysis of Fluorescence Signals and Objects

PICAFSO is a Python-based image-analysis code for quantitative multichannel fluorescence microscopy.

It helps to perform particle detection, watershed-based segmentation, background subtraction, fluorescence intensity quantification, statistical analysis (mean, standard deviation, and standard error of the mean), fluorescence normalization, and quality-control visualization.
